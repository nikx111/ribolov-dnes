# Риболов днес · Варна

Приложение за телефона: какво, къде, с какво и как да ловиш от брега във Варна днес, по живите данни за морето и времето.

Отвори **https://nikx111.github.io/ribolov-dnes/** и от менюто на браузъра избери „Добави към началния екран“.

Данни: [Open-Meteo](https://open-meteo.com/), [НИМХ Варна](http://varna.meteo.bg/) (свалят се на всеки час в `nimh.json`), места © [OpenStreetMap](https://www.openstreetmap.org/copyright).
